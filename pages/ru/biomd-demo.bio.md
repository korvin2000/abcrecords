## 9. Стихи и песенный текст

Строфа в тройных обратных кавычках сохраняет разбиение на строки, переносится
по ширине колонки и никогда не уезжает за край страницы.

```
Когда умру,
Схороните меня с гитарой
В речном песке.

Когда умру...
В апельсиновой роще старой,
В любом цветке.
```

Два блока подряд читаются как строфы одного стихотворения:

```
Когда умру,
Стану флюгером я на крыше,
На ветру.
```

```
Тише...
Когда умру!
```

Одна длинная строка — тот случай, когда разбиение утрачено в источнике:
она переносится как обычная проза, а не превращается в горизонтальную полосу.

```
Начинается плач гитары, Разбивается чаша утра. Начинается плач гитары. О, не жди от нее молчанья! не проси у нее молчанья!
```

::: columns

::: column

```
А одна струна — тетива,
зазвеневшая из темноты.
Вместо стрел в колчане — слова.
А когда захочу — цветы.
```

:::

::: column

```
А вторая струна — река.
Я дотрагиваюсь до нее.
Я дотрагиваюсь слегка.
И смеется детство мое.
```

:::

:::

Ограждение с именем языка — это по-прежнему код: моноширинный шрифт и
собственная горизонтальная прокрутка, а не прокрутка страницы.

```json
{ "id": "11", "title": "BioMD 1.6 Conformance", "md": "/biomd-demo.bio.md" }
```

## 10. Якоря (`::: anchor`)

не затрагивает адрес страницы. Обе записи равноправны — однострочная
`:: anchor{#имя}` и полная:

::: anchor
id: top-of-page
:::

- [К стихам](#verse) — однострочная запись
